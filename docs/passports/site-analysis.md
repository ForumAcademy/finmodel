## Как устроено

- Формулы анализа (`ANALYSIS_FORMULAS`) не входят в расчёт проекта: для каждого варианта строятся его вводные, и вариант считается полным расчётом проекта (`computeProject`).
- Максимальная цена участка (`F.VAR.LAND_MAX`: NPV акционера = 0, решение пользователя 16.11.2026) и «что, если» (`F.VAR.SENSITIVITY`: цена продаж и ключевая ставка, шаги `VAL.SENS_*` в справочнике) считаются по пробным полным расчётам лучшего варианта (`report.ts`); формулы только интерполируют между пробами.
- Лучший вариант выбирается по итогам полных расчётов (`F.VAR.BEST`); итоги лучшего запоминаются в проекте (`snapshot`) для списка проектов.
- Здания на участке (вкладка «Ограничения»): площадь под снос обязательна (0 — сносить нечего); объём по техпаспорту главнее оценки «площадь × высота этажа `SITE.DEMOLITION_STOREY_HEIGHT`». Район для зоны нормативов соцобъектов — из адреса (`GEN.LOCALITY`); не найден — зона с бо́льшим нормативом и предупреждение.
- Экран кэширует итоги вариантов по вводным и версии справочника.

## Ловушки

- Рынок пока по ручной таблице аналогов; с ЕИСЖС её заменит выборка (модуль BENCH, `docs/00` §9).
- Нормативы регионов — только из `data/regions.yaml`; нет значения — ручной ввод с документом.
