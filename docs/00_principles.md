# Принципы модели: трассируемость каждой цифры

Главное требование: у любого числа на экране можно спросить «откуда?» и получить ответ со ссылкой. Ответ идёт по цепочке до исходных параметров, а у каждого параметра есть источник.

## 1. Три реестра: единственный источник правды

| Реестр | Файл | Что содержит |
|---|---|---|
| Источники | `data/sources.yaml` | **Общие** источники (`scope: global`): законы, НПА, статистика, госсервисы, рыночные данные — id, уровень доверия, реквизиты, **URL**, дата проверки, для чего используется; а также **типы проектных источников** (`scope: project`), конкретные документы которых хранятся внутри проекта (раздел 6) |
| Параметры | `data/parameters.yaml` (+ `capex_items.yaml`, `regions.yaml`) | Каждое исходное значение: единица, диапазон, `source_ids`, обоснование, инструкция заполнения, откуда пришло из исходного Excel |
| Формулы | `data/formulas.yaml` | Каждый расчётный показатель: выражение через ID, зависимости, **почему так**, **что отклонено**, источник, контрольный пример |

Документация (`docs/03–05`) генерируется из YAML скриптом `scripts/render_docs.py`, поэтому текст и расчёт не расходятся. Код расчётного ядра реализует формулы 1:1 по ID и не содержит чисел, которых нет в реестрах.

## 2. Шкала источников

| Уровень | Что это | Примеры | Требования |
|---|---|---|---|
| 1 | Закон, НПА, официальное разъяснение | НК РФ, 214-ФЗ, ГрК, НЦС Минстроя, письма Минфина/ФНС, региональные акты | URL на текст статьи/акта |
| 2 | Официальная статистика, госсервисы | ЦБ (ключевая ставка, статистика ПФ), МЭР (прогноз), ЕИСЖС, ФНС (ставки), НСПД (кадастр) | URL + дата выгрузки |
| 3 | Рыночные данные | Условия банков, аналитика ДОМ.РФ, консультанты, выборка аналогов (F.BENCH.MARKET_PRICE, F.BENCH.MARKET_PACE) | URL + сохранённая выборка (не менее BENCH.MARKET_MIN_COMPS = 3 аналогов) |
| 4 | Данные компании / проекта | Бенчмарки компании (сметы, КС-2, договоры завершённых проектов); документы проекта: term sheet банка, ГПЗУ, ППТ, ТЭП архитектора | Вложение документа (Vercel Blob) или ссылка на выборку бенчмарков |
| 5 | Экспертная оценка | Темп продаж на ранней стадии, премия за риск | **Автор, дата, обоснование, диапазон min–max.** Параметр автоматически попадает в анализ чувствительности |

На дашборде показывается, какая доля NPV зависит от параметров уровня 5: это отвечает на претензию «цифры экспертные».

## 3. Статусы

- `verified` — значение и ссылка сверены с текстом источника.
- `needs_verification` — источник найден, но формулировку, пункт или редакцию нужно сверить перед релизом (перечень формирует валидатор).
- `project_input` — вводится по проекту, без значения по умолчанию.
- `expert_allowed` — допускается уровень 5 с обязательными полями.

## 4. Соглашения

- **Шаг расчёта** — месяц; отчёты агрегируются в кварталы и годы.
- **Деньги** хранятся в рублях. Суммы затрат задаются без НДС с флагом `vat_included`; денежный поток — с НДС. Цены продаж задаются так, как в договоре (с НДС, если продукт облагается).
- **Доли** хранятся как доли (0,22), не проценты.
- **Знаки:** поступления > 0, платежи < 0 только в сводном CF. В модулях все суммы положительные.
- **Даты** — только даты (ISO 8601), никогда не текст.
- **Нет ручных перебивок:** если значение получено формулой, ввести его руками можно только через явный параметр `*_OVERRIDE` с документом.
- **Каждое значение исходного Excel** имеет строку в `legacy/legacy_values_map.csv` с вердиктом. Удаление (verdict = remove) — тоже решение, и оно записано.

## 5. Паспорт показателя (как видит пользователь)

По клику на любое число сервис показывает:

1. Значение и единицу.
2. Формулу словами и через ID (из `formulas.yaml → expr`).
3. Почему считается так (`rationale`) и какие варианты отклонены (`rejected`).
4. Дерево зависимостей до исходных параметров.
5. Для каждого исходного параметра: значение, источник (уровень, название, **кликабельная ссылка**, дата проверки), кто и когда изменил.

## 6. Общие и проектные источники

Источники делятся на два реестра, и они не смешиваются.

| | Общие источники | Проектные источники |
|---|---|---|
| Что это | Законы, НПА, статистика ЦБ/Росстата/МЭР/Минстроя, ЕИСЖС, условия банков, бенчмарки компании | ГПЗУ, ППТ, ТЭП архитектора, договор на участок, term sheet банка, выборка аналогов для этого ЖК, экспертные оценки |
| Где хранятся | Справочник (`data/sources.yaml`, `scope: global`; в БД — `sources.scope = global`) | Внутри проекта (`sources.scope = project`, `project_id`); в общий справочник не попадают |
| Уровни | 1–3; уровень 4 — только бенчмарки компании (раздел «Бенчмарки») | 4–5 |
| Подтверждение | URL на первичный документ, дата проверки | Вложение (Vercel Blob), автор, дата; для уровня 5 — обоснование и диапазон min–max |
| Кто меняет | Администратор (методолог), через журнал изменений справочника | Аналитик — автор проекта |

`data/sources.yaml` содержит и **типы** проектных источников (`S_PROJECT_DOCS`, `S_BANK_TERMSHEET`, `S_EXPERT`) с `scope: project`: параметры ссылаются на тип, а конкретный документ прикладывается в проекте. При копировании проекта его проектные источники копируются вместе с ним (вложения — по ссылке на тот же файл).

## 7. Версии справочника

- Справочник (методика, нормативы и ставки, общие источники, бенчмарки) имеет версии — `spec_version`. Опубликованная версия неизменяема.
- Каждая версия расчёта проекта хранит версию справочника, на которой она посчитана, и воспроизводится по ней с тем же результатом.
- Изменение справочника **не пересчитывает проекты автоматически**. На карточке проекта появляется уведомление «Доступна новая версия справочника» со списком изменений, которые затрагивают проект, и влиянием на NPV, IRR и маржу. Пересчёт — по кнопке и создаёт новую версию проекта; старая сохраняется.
- Утверждённый проект пересчитывается только после отдельного подтверждения.

## 8. Роли

| Роль | Проекты | Справочник |
|---|---|---|
| Администратор (методолог) | Все действия со всеми проектами | Редактирует методику, нормативы, общие источники, бенчмарки; публикует версии; рассматривает заявки. Каждое изменение — с обоснованием и источником, попадает в журнал |
| Аналитик | Создаёт проекты, редактирует и утверждает свои; чужие — просмотр, копирование, выгрузка | Только чтение; может подать заявку на изменение методологу |
| Наблюдатель | Просмотр и выгрузка в Excel | Только чтение |

## 9. Бенчмарки: выборки вместо экспертных оценок

- Стартовая цена, темп продаж и расценка статьи бюджета могут ссылаться на **сохранённую выборку**: список аналогов со ссылками, корректировки, итоговая статистика, дата выборки. Уровень источника такого параметра — **3** (аналоги рынка) или **4** (расценки компании), а не 5.
- Правила статистики — формулы `F.BENCH.*` и параметры `BENCH.*` (Справочник → Методика; значения меняет только методолог):
  - аналоги рынка: цена аналога — средневзвешенная по проданной площади; приведение к дате оценки индексом цен ДДУ; корректировки на локацию, класс, отделку, стадию — каждая с обоснованием; итог — медиана при 5 и более аналогах, средневзвешенная по близости при 3–4, меньше 3 — только с экспертным обоснованием; темп — медиана нормированных темпов (доля от экспозиции в месяц);
  - окна данных: цены — 6 месяцев (расширение до 12, если аналогов меньше 5), не старше 12 месяцев; темпы — 12 месяцев; данные раньше последнего структурного сдвига рынка (01.07.2024) не используются;
  - расценки компании: ставка на единицу базы без НДС, приведение к дате оценки индексами Минстроя и к региону — коэффициентами НЦС; итог — медиана по сопоставимым проектам (класс, этажность ±30%, конструктив, давность до 5 лет); меньше 3 проектов — значение по НЦС с пометкой «экспертное».
- Для любой выборки показываются n, медиана, среднее, минимум, максимум, квартили, коэффициент вариации. Большое расхождение среднего и медианы или большой разброс требуют комментария аналитика. **Выбросы подсвечиваются, но не удаляются автоматически**: исключить аналог можно только вручную с причиной, и это попадает в журнал.
- Выборка **замораживается в версии проекта**: пополнение базы аналогов или расценок не меняет посчитанную (в том числе утверждённую) модель без пересчёта — так же, как с версиями справочника.
- В паспорте показателя по клику видны все аналоги выборки, их веса и корректировки.
