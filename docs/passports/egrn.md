# Паспорт: выписка ЕГРН (packages/egrn-import)

**Что это.** Распознавание документа по участку в поля проекта: выписка ЕГРН и инвестиционное предложение продавца (решение пользователя 18.11.2026). Что не нашлось, финансист вводит вручную со ссылкой на документ.

## Файлы

| Файл | Что в нём |
|---|---|
| `packages/egrn-import/src/index.ts` | `parseEgrnXml` (электронная выписка Росреестра, в том числе ZIP с подписью), `parseEgrnText` (текст PDF), `readEgrnFile`, `foundSummary` |
| `packages/egrn-import/src/offer.ts` | `parseOfferText` — инвестиционное предложение в PDF (свободная вёрстка): поиск по ключевым словам в тексте без пробелов (pdf.js режет числа: «79 5 00 м2»); `looksLikeOffer`. В `index.ts` — `readPlotDocument`: PDF с признаками предложения — предложение, остальное — выписка |
| `packages/egrn-import/src/xml.ts` | Небольшой разбор XML без зависимостей |
| `apps/web/lib/egrn.ts` | Чтение файла в браузере: текст PDF достаёт pdf.js, поля распознаёт пакет |
| `packages/egrn-import/test/fixtures/` | Пример выписки в XML и текст PDF; текст предложения по Рябиновой, 28а (как его отдаёт pdf.js) |

## Как устроено

- Результат — поля участка для `plot.ts` с меткой «из источника» и ссылкой на документ проекта.
- Сам документ хранится в проекте (проектный источник), в `data/sources.yaml` — только его тип.

- Предложение: поля участка — «из источника» с документом «Инвестиционное предложение»; значения выписки ЕГРН главнее и не заменяются (`engine/src/offer.ts`). Скан без текста не читается — сообщение, ввод вручную.
