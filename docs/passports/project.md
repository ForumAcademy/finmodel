# Паспорт: проект, справочник в браузере и хранение

**Что это.** Запись проекта (участок, документы, история, метки происхождения), файлы проекта и справочника, версии справочника у проекта. Базы данных нет (решение пользователя 29.09.2026): всё в браузере и в файлах. Целевая схема с сервером — `docs/01_architecture.md`.

## Файлы

| Файл | Что в нём |
|---|---|
| `packages/engine/src/plot.ts` | Поля участка, метки происхождения (`ORIGIN_LABEL`), экспертное значение, новый проект с кадастровым номером и без, регион по номеру или адресу, документы, «было → стало», история, статус проекта |
| `packages/engine/src/projectfile.ts` | Файл проекта: сборка, чтение, открытие, конфликт имён |
| `packages/engine/src/book.ts` | Справочник допущений компании: правка новой версией, файл справочника, версия у проекта, «Обновить» |
| `packages/engine/src/reference.ts` | Строки экрана «Справочник»: стандартные значения, нормативы регионов, формулы, источники, история версий |
| `apps/web/lib/store.ts` | IndexedDB: проекты, документы, справочник. Сервер подключается заменой этого файла |
| `apps/web/lib/files.ts` | Только байты: base64, sha256, скачать и прочитать файл |

## Хранение сейчас

- **Файл проекта** (формат `finmodel-project`, версия 1) — один JSON: `project` (запись проекта как есть: участок, метки происхождения, документы, история), `reference` (полная версия справочника, на которой посчитан проект), `files` (документы по id: имя, тип, размер, sha256, байты в base64). На сервере `project` ложится в таблицу проектов, `files[].data` заменяется ссылкой на хранилище файлов, остальное без изменений.
- **Открытие проекта из файла**: документы получают новые id; если проект с таким названием уже есть — вопрос «Заменить» или «Создать копию». Если версии справочника из файла нет в браузере или она другая, проект хранит её у себя (`assumptionsSnapshot`) и считается на ней до кнопки «Обновить».
- **Файл справочника** (формат `finmodel-reference`) — все версии по порядку. Загрузка добавляет новые версии; если истории разошлись, версии браузера с точки расхождения заменяются версиями из файла, а проекты на заменённых версиях сохраняют свою версию.
- **Правка справочника**: в интерфейсе правятся стандартные значения компании: значение, статус, «Откуда», пояснение. Сохранение создаёт новую версию с автором и описанием; проекты переходят на неё кнопкой «Обновить», переход пишется в историю проекта. Налоги, ставки по закону и нормативы регионов в интерфейсе не правятся: они привязаны к документам и меняются через `data/*.yaml`.

## Ловушки

- Пустое значение не равно нулю: показатель «не учтено» (`docs/00` §5).
- Метки происхождения — только четыре из `docs/00` §5; тексты меток — `ORIGIN_LABEL`.
