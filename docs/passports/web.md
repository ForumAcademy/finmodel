# Паспорт: интерфейс (apps/web)

**Что это.** Next.js (App Router). **Расчётов нет**: экраны вызывают ядро и показывают результат; любая арифметика — в ядре с тестом. Тексты — по `docs/06_zadanie.md` §7.

## Адреса

| Адрес | Экран | Компонент |
|---|---|---|
| `/` | Проекты | `components/ProjectsScreen.tsx`, `NewProjectModal.tsx` |
| `/projects/[id]?sec=…&tab=…` | Проект: ★ Итог (открывается первым), 1 Участок, 2 Что можно построить, 3 Рынок, 4 Варианты, 5 Финмодель (этап 6) | `ProjectScreen.tsx`, `AnalysisScreens.tsx`, `MapPicker.tsx` |
| `/reference/[section]` | Справочник: стандартные значения, нормативы регионов, формулы, источники, где взять данные, история версий, что нового в сервисе | `ReferenceScreen.tsx`, `lib/reference-sections.ts` |
| `/api/zcyc` | Кривая ОФЗ через сервис, если браузер не пускает на биржу | `app/api/zcyc/route.ts` |

| 5 Финмодель | `model` | заглушка до этапа 6 | «этап 6» |

- Сверху шага — ответ одной фразой (`siteView.potentialHeadline`, `marketHeadline`; у вариантов — `compareTable.why`).
- Поля шага — `FieldTable` (`components/ui.tsx`): пустые обязательные — список «Не хватает» с «Где взять?» по нажатию, остальное — таблица «Показатель · Значение · Откуда». Метки происхождения — серым; жёлтым — только то, чего не хватает.
- Старые адреса ведут на новые шаги (`app/projects/[id]/page.tsx`): `sec=docs` → Участок/Документы, `sec=compare` → Варианты, `sec=site&tab=Сделка` → Участок/Сделка.

## Итог и карточка проекта

- «Итог» (`sec=summary`, по умолчанию): время расчёта и «Пересчитать» (заново считает все варианты и запоминает итог для карточки), «Сервис обновился» — изменения сервиса после прошлого расчёта проекта, лучший вариант и итоговый отчёт (`Report.tsx`: плитки прибыли, IRR, NPV и окупаемости, максимальная цена участка с запасом к цене продавца, графики продаж и окупаемости в SVG, таблица «что, если», «Уточнить перед решением»; пробные расчёты идут по одному через `setTimeout` с ходом «пробный расчёт N из M» и кешем), все показатели лучшего — под «Все показатели лучшего варианта» (`siteView.compareTable`), лидеры по прибыли и долгу (`siteView.leaders`), «Что нужно ввести» — все недостающие значения со всех экранов (`summary.todoList`), внизу версия справочника и «Обновить».
- Карточка в списке: итог или причина, почему его нет; «Данные изменены» и «Посчитан» (`summary.cardStatus`). Запомненный итог не меняет дату изменения данных.
- **«Что нового в сервисе»** — `SERVICE_UPDATES` в `engine/src/summary.ts`. Каждый PR, который меняет расчёт или экраны, добавляет туда строку для финансиста (дата, что изменилось словами); по ней проект показывает «Сервис обновился» и карточка — «нужно пересчитать».

## Прочее

- `components/ui.tsx` — метка происхождения (`OriginTag`), поля экспертного значения, окна, уведомления, пометка «Где взять данные» (`WhereToFind`).
- «Где взять данные» обязательна у каждого поля ручного ввода участка и ограничений: тексты — `where` в `PLOT_FIELDS` (`engine/src/plot.ts`), `hint` в `SITE_FIELDS` и `ZOUIT_WHERE` (`engine/src/site.ts`). Показывается в окне изменения поля, при создании проекта и под пустым полем. Раздел Справочника «Где взять данные» (что даёт источник, как получить и внести) — `engine/src/where.ts`, ссылки — из `data/sources.yaml`.
- `lib/store.ts`, `lib/files.ts` — хранение в браузере и файлы ([project](project.md)); `lib/egrn.ts` — выписка ЕГРН ([egrn](egrn.md)); `lib/zcyc.ts` — кривая ОФЗ.
- Сборка: `pnpm build` (перед `next build` собирается справочник `packages/spec`); `output: "standalone"` — сайт одним пакетом для сервера. Vercel (корень `apps/web`) — запасной до 30.11.2026.

## Где работает

Сервер в России (VPS Хостленд), решение пользователя 16.11.2026: запросы к госисточникам и порталу открытых данных Москвы идут с российского адреса.

- **Установка.** Workflow «Сайт на сервер» (`.github/workflows/web-deploy.yml`) при слиянии в `main` (изменения `apps/web`, `packages`, `data`, `services/web`): тесты, сборка, пакет (`.next/standalone` + `.next/static` + `services/web/deploy`), копирование по SSH (секреты `SERVER_HOST`, `SERVER_USER`, `SERVER_SSH_KEY`), `deploy/install.sh`.
- **На сервере.** Пользователь `finmodel` без root. `~/web/releases/<дата-коммит>` — три последние версии, `~/web/current` — рабочая; `~/web/node` — свой Node.js той же версии, что в сборке (системный Node других сайтов не трогаем). Служба `systemd --user` `finmodel-web` на `127.0.0.1:3400`; пределы — 512 МБ памяти, половина ядра (`deploy/finmodel-web.service`).
- **Откат.** Если новая версия не ответила за 30 секунд, `install.sh` возвращает предыдущую и завершается с ошибкой.
- **Снаружи.** nginx, поддомен `ocenka.orientirgpz.com` (`deploy/nginx-ocenka.conf`), HTTPS — certbot. Ставит владелец сервера от root, как для сборщика.
- **Ключ портала открытых данных Москвы.** Секрет GitHub `DATA_MOS_API_KEY` → `~/web/.env` (права 600, в журнал не выводится) → переменная окружения сайта `DATA_MOS_API_KEY`. Нет секрета — ключа нет, сайт работает с ручным вводом.
- **Проекты в браузере** привязаны к адресу сайта: при смене адреса пользователь переносит их файлом проекта (`lib/files.ts`).
- Целевые вкладки проекта (ТЭП, Бюджет, План продаж, … Дашборд) — `docs/06_zadanie.md` §6.
