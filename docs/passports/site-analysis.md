# Паспорт: анализ участка

**Что это.** Ограничения участка, рынок по аналогам, варианты освоения и выбор лучшего. Задание — `docs/06_zadanie.md` §4 (B, C, E, G).

## Файлы

| Файл | Что в нём |

## Как устроено

- Формулы анализа (`ANALYSIS_FORMULAS`) не входят в расчёт проекта: для каждого варианта строятся его вводные, и вариант считается полным расчётом проекта (`computeProject`).
- Лучший вариант выбирается по итогам полных расчётов (`F.VAR.BEST`); итоги лучшего запоминаются в проекте (`snapshot`) для списка проектов.
- Экран кэширует итоги вариантов по вводным и версии справочника.

## Ловушки

- Рынок пока по ручной таблице аналогов; с ЕИСЖС её заменит выборка (модуль BENCH, `docs/00` §9).
- Нормативы регионов — только из `data/regions.yaml`; нет значения — ручной ввод с документом.
