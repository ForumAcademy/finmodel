# Оценка участка под ЖК

Веб-сервис оценки потенциала земельного участка под жилую застройку. На входе — кадастровый номер и площадь участка; на выходе — варианты освоения, лучший вариант, график продаж, окупаемость, рентабельность и остаточная стоимость земли. Регионы первой очереди — Москва и Московская область. Каждое число привязано к источнику со ссылкой.

Задание — `docs/06_zadanie.md`. Правила работы — `CLAUDE.md`.

## Что внутри

| Путь | Содержание |
|---|---|
| `data/*.yaml` | Источник правды: источники, параметры, статьи бюджета, формулы, регионы, справочник допущений компании |
| `docs/MAP.md`, `docs/passports/` | Карта модулей и паспорта: что где лежит и как устроено |
| `docs/00–02` | Принципы и шкала источников, стек и целевая схема, аудит исходного Excel |
| `docs/03–05` | Каталог формул, параметров и источников *(генерируется из `data/` командой `python scripts/render_docs.py`, в git не хранится; собранные файлы — в артефакте `docs-03-05` каждого прогона CI)* |
| `legacy/` | Исходный Excel «Кальк Саевой привязка КОД.xlsx» и полная карта его ячеек |
| `tests/cases/derbenevskaya_legacy.yaml` | Регрессионный кейс: вводные исходника, цели сверки, обязательные отличия после исправлений |
| `scripts/` | Валидатор спецификации, генератор документации, построение карты и кейса исходного Excel |
| `packages/spec` | Справочник для TypeScript (`src/generated` собирается при `pnpm install`, в git не хранится) |
| `packages/engine` | Расчётное ядро, расчёт проекта, пояснения и отчёты по периодам |
| `packages/excel-import` | Загрузка готовой финмодели из Excel по карте |
| `apps/web` | Интерфейс (Next.js) |

Спецификация, ядро, карта Excel и тесты перенесены из `ForumAcademy/financialmodelstroyka` (состояние на 28.09.2026). Старый интерфейс не переносился.

## Быстрый старт

```bash
pip install pyyaml openpyxl
python scripts/validate_spec.py   # 0 ошибок, список того, что сверить перед релизом

# Node.js 22+, pnpm 10
pnpm install
pnpm typecheck && pnpm lint && pnpm test
pnpm dev                          # http://localhost:3000
```
